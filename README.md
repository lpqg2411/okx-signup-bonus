### Maker versus taker fees

A taker order immediately matches existing liquidity in the order book. A maker order adds liquidity by resting on the order book before it is filled.

A market order is usually treated as a taker order, but a limit order is not automatically a maker order. A limit order that matches immediately can also be charged at the taker rate. The execution result determines the fee classification.

For a new user completing a bonus task, this matters because the trading fee can reduce the value of a small qualifying trade. Check the order panel before submitting the trade, especially if the promotion requires one specific trade rather than cumulative volume.
